# Inventory Hub 桌面版

Windows x64 安装包与自动更新文件。

[下载最新版本](https://github.com/Darrowyu/inventory-hub-releases/releases/latest)

- 首次使用或从 1.2.6 及更早的桌面版升级：下载安装包，安装到原目录。
- 从 1.3.0 开始，程序启动后自动检查并下载更新；也可以在托盘菜单选择“检查更新”。下载完成后选择“重启更新”，或稍后从托盘退出时安装。
- 关闭窗口会隐藏到托盘；彻底退出请使用托盘菜单。
- 更新保留本地数据目录中的数据库、图片与备份。

本仓库仅发布安装包和更新元数据，应用源码、账号和用户数据不在本仓库。
